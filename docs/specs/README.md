# Specifications

Specification documents follow the naming convention
`SPEC-XXX-feature-name.md` and move through lifecycle folders as work
progresses:

| Folder | Meaning |
|---|---|
| `backlog/` | Proposed / not yet started |
| `active/` | Currently being implemented |
| `review/` | Implementation complete, under review |
| `completed/` | Implemented, reviewed, and in use (includes as-built specs) |

Move a spec file between folders to reflect its current status.
