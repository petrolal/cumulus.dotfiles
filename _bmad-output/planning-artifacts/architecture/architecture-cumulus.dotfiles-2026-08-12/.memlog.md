- (question) User asked: Can we migrate all rust files to scala with graalVM?
- (insight) Brownfield context: cumulus.dotfiles consists of desktop WM tools (autotiling, pickers, theme, refresh) targeting Sway/Wayland with sub-millisecond CLI startup and low memory footprint.
- (decision) User selected Coaching path workflow
- (decision) Deliverable target: Architecture Spine only (ARCHITECTURE-SPINE.md)
- (decision) Migrate 100% of Rust files in cumulus.dotfiles to Scala 3 with GraalVM Native Image compilation (Option A)
- (constraint) Maintainer ergonomics: User requested JVM-based ecosystem (Scala) for familiar language ergonomics and maintainability
- (decision) Packaging Architecture: Single multi-call GraalVM native binary ('cumulus') with symlinks ('cumulus-<command> -> cumulus'). Binds executable structure, prevents 24x build time multiplier.
- (decision) Stack & Ecosystem: Scala 3.5+, sbt with sbt-native-image 0.5.0, JDK 21 GraalVM base. Binds language runtime and build framework.
- (decision) System & Serialization Libraries: Use os-lib (0.11.9-M8) for filesystem/process IO and uPickle (4.4.3) for JSON. Prevents heavy reflective frameworks (e.g. Jackson/Akka) that require complex GraalVM reflection configuration files.
