- (decision) Paradigm: Native Monolithic CLI Orchestrator. The system is a single Scala 3 / GraalVM Native Image binary ('polyomino') that acts as a multi-command dispatcher.
- (decision) Side-Effect Isolation: Direct inline side-effects (os.proc, os.write) are acceptable. No strict IoC or dry-run abstractions required.
- (decision) State Ownership: The Context object is a mutable registry, allowing modules to update and pass state during execution.
- (decision) Error Handling Contract: Fail-fast. Subcommands return PolyominoError and halt immediately on failure without attempting automated rollbacks. The user is responsible for manual remediation.
- (decision) [ADOPTED] Deployment & Distribution: The CLI is distributed as a GraalVM native image, built via GitHub Actions, and released to Maven Central/GitHub Releases for fast zero-dependency bootstrapping.
